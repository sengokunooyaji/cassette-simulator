# Cassette Deck Simulator

手持ちの曲をカセットテープの A 面・B 面に収録し、テープの音で再生する Web Audio アプリです。カセット再生の音響特性をブラウザ上でリアルタイムに再現します。「普及モデル」と「高級モデル」を切り替え、原音と聴き比べられます。

ビルド不要の静的ページで、ブラウザだけで動作します。

## 再現する要素

| 要素 | 内容 |
|---|---|
| 周波数特性 | 低域のロールオフ、ヘッドバンプ（低域の小さな山）、ギャップ損失による高域の減衰 |
| ワウ・フラッター | 0.6Hz のワウ、キャプスタン回転周期のフラッター、帯域制限したランダムな揺らぎ。遅延時間を変調して再現します |
| テープヒス | S/N 比から決めたレベルのノイズ |
| 飽和 | tanh による飽和。録音時の高域プリエンファシスを通すため、高域から先に詰まります |
| ヘッドのアジマスずれ | 左右チャンネルの時間差。モノラルにまとめると高域が打ち消されます |
| ドルビー B / C / S | 音量に追従して動くコンパンダー。デコードの有無、未デコード再生、テープ誤差によるミストラッキング |
| dbx | 録音時 2:1 圧縮・再生時 1:2 伸長を実際に行う。ブリージング、テープ誤差の 2 倍拡大、未デコード再生の圧縮音 |
| テープの劣化 | 10〜50 年。高域の減衰、ドロップアウト、転写によるポストエコー、テープの伸びによるワウの増加 |

## 機種プリセット

| | 普及モデル | 高級モデル |
|---|---|---|
| 想定 | ラジカセ／ポータブル級・2 ヘッド | 3 ヘッド・クローズドループ級 |
| 周波数特性（±3dB）TYPE I / II / III / IV | 50Hz– 10 / 12 / 12 / 13 kHz | 20Hz– 18 / 20 / 19 / 21 kHz |
| ワウ・フラッター | 0.25% WRMS | 0.04% WRMS |
| S/N 比（NR なし）TYPE I / II / III / IV | 47 / 51 / 50 / 52 dB | 57 / 60 / 59 / 61 dB |
| 最大出力レベル TYPE I / II / III / IV | +3 / +4 / +5 / +7 dB | +6 / +7 / +8 / +11 dB |
| アジマスずれ | 15′（L/R 差 73µs） | 2′（10µs） |
| ドルビー B / C / S | なし | あり |
| dbx | なし | あり |

数値は 1970〜80 年代のカタログ値の代表的な水準をもとにした推定で、特定の製品の再現ではありません。レベルはドルビーレベル（メーターの 0dB）を −6dBFS（実効値）とした基準で扱っています。0dBFS までピークがある最近の音源は、録音レベル 0 のときピークメーターで約 +3dB を指します。大きな音源を録音するときに、録音者がレベルを合わせる状態に相当します。

## 操作

- **音源**：ピンクノイズ、3150Hz 試験信号、カセットに収録した曲（WAV / MP3 / FLAC / AAC など）
  - 3150Hz はワウ・フラッター測定の標準信号で、音程の揺れが最もはっきり聴き取れます。
  - 曲はストリーミング再生するので、長いファイルも読み込めます。
- **カセット／原音**：瞬時に切り替えて比較できます。
- **音源**：ピンクノイズと 3150Hz 試験信号は、上部の「再生」で鳴らします。「カセット」を選ぶと、収録した曲をデッキの操作ボタンで再生します。
- **テープ**：TYPE I（ノーマル）／TYPE II（ハイポジ）／TYPE III（フェリクローム）／TYPE IV（メタル）、録音時の NR（なし／ドルビー B・C・S／dbx）、再生側のデコード（高級モデルのみ）
  - 飽和の前にかける高域プリエンファシスをテープごとに変えています（I 6dB、II・III 4.5dB、IV 2.5dB）。ノーマルほど高域から先に詰まり、メタルは高域まで余裕があります。TYPE III はクローム層を重ねた二層テープで、低域の余裕はノーマル寄り、高域はハイポジ寄りです。
- **ドルビー B / C / S**：録音時は、小さい音ほど高域（S は低域も）をシェルフで持ち上げ、再生時は逆に戻します。再生側は実機と同じく、復号後の信号を検出する帰還型です。

  | | 最大の持ち上げ（ヒス低減） | −40dB での持ち上げ（5kHz） | 録音→再生の通し誤差（実測） |
  |---|---|---|---|
  | B | 高域 10dB | 約 10dB | 0.01dB |
  | C | 高域 20dB（2 段） | 約 17dB | 0.05dB |
  | S | 高域 24dB（2 段）＋低域 10dB | 約 22dB | 0.11dB |

  テープの高域が落ちていると（普及モデル、経年劣化など）デコードがずれ、音色が変わります（ミストラッキング）。デコードしないで再生すると、静かな部分ほど高域が持ち上がって聴こえます。周波数特性グラフでは、未デコード時の曲線を −20dB（ドルビーレベル基準）で測った値として表示します。
- **dbx**：録音時に 2:1 で圧縮し、再生時に 1:2 で伸長します。音量に追従して動くので、本物の dbx と同じ癖が出ます。
  - ヒスは約 30dB 下がりますが、静かな曲ではヒスが音に合わせて浮き沈みします（ブリージング）。
  - 伸長でレベル差が 2 倍になるため、テープの周波数特性の誤差（劣化による高域低下など）も 2 倍に拡大されます。
  - 普及モデル、またはデコード OFF で再生すると、強く圧縮され高域の強調された平板な音になります。
  - 検出は整流平均（10Hz 平滑）、高域エンファシスは 10dB です。テープ経路が平坦なとき、録音→再生の通しの誤差は −30〜+6dB の範囲で ±0.2dB 以内です。
- **テープの劣化**：「経年劣化あり」にすると、10〜50 年のスライダーで次の現象を加えます。

  | | 10 年 | 30 年 | 50 年 |
  |---|---|---|---|
  | 高域の減衰（5kHz 以上のシェルフ） | −1dB | −4dB | −8dB |
  | ドロップアウト（瞬間的な音の欠けと高域の落ち込み） | 約 2 回/分 | 約 12 回/分 | 約 31 回/分 |
  | 転写によるポストエコー（約 1.8 秒後） | −55dB | −48dB | −42dB |
  | テープの伸びによるワウ・フラッター | ×1.03 | ×1.29 | ×1.8 |

  このほか、減磁による −0.3〜−1.5dB の出力低下と、わずかなヒスの増加を加えます。
- **録音レベル**：上げると飽和が強まります。出力の音量は自動で揃えます。
- **ワウ・フラッター量**、**テープヒス**：誇張したり、消したりできます。
- **表示**：周波数特性（L/R、モノラル合成、もう一方の機種）、回転ムラ（テープ速度偏差の実時間表示）、再生補正
- **レベルメーター**：アナログ針式の L/R 2 連メーターで、録音レベル（テープで飽和する前の信号）を表示します。
  - **PEAK**：速い立ち上がりと、約 13dB/s のゆっくりした戻り。ばね感のある針の動き
  - **VU**：300ms の積分と約 1.5% のオーバーシュート（VU メーターの規格どおりの応答）
  - 目盛りは実物の VU メーターと同じく電圧に比例します（0dB が振れ幅の約 71%、+3dB が最大）。0dB はドルビーレベルです。
  - PEAK メーターの目盛りは dB 等間隔で −20〜+8dB です（上級デッキのピークメーターと同じ範囲）。
  - PEAK ランプは、選んだテープの最大出力レベルを超えると点灯します。

## カセットへの収録と再生

- **テープ長**：C-46 / C-60 / C-90 / C-120（片面 23 / 30 / 45 / 60 分）
- **曲の追加**：「曲を追加」またはドラッグ＆ドロップ（複数可）。A 面に入るだけ入れ、続きは B 面に入れます。両面に入りきらない曲は収録しません。
  - 各面の頭に 5 秒のリーダー、曲間に 4 秒の無音を入れます。最後の曲のあとは、面の終わりまで無音（ヒスのみ）が続きます。
  - 曲ごとに、並べ替え（↑↓）、反対の面へ移動、削除ができます。
  - 「テープの入れ替え」で、全曲を消去して新しいテープにします（A 面の先頭に戻ります）。誤操作を防ぐため、2 回押して確定します。テープ長を短くして入りきらなくなった曲は、反対の面へ移すか、外します。
- **操作**：|◀◀ 前の曲の頭へ／▶ 再生／■ 停止／▶▶| 次の曲の頭へ／A⇄B
  - |◀◀ ▶▶| は頭出しです。リールを高速で回して曲の頭まで巻き（最長約 1 秒、無音）、再生中だったらそのまま再生を続けます。
  - |◀◀ は、曲の頭から 3 秒以内なら前の曲へ、それ以降なら今の曲の頭へ戻ります。
  - 最後の曲で ▶▶| を押すと面の終わりまで巻き、リバース方式に従って停止または折り返します。
- **リバース方式**
  - 手動で裏返す：面の終わりで停止します。A⇄B でカセットを裏返します。
  - オートリバース：A 面の終わりで B 面へ折り返し、B 面の終わりで停止します。
  - 連続リバース：A 面と B 面を繰り返します。
  - A⇄B を押すと、もう一方の面の頭から始まります（巻き戻してから裏返すのと同じ）。再生中に押した場合は、裏返す間（手動 約 1 秒、オートリバース 約 0.45 秒）を置いて再生を続けます。カセットは裏返る動きで描きます。
  - オートリバースで B 面を再生するときは、ヘッドが反転するため、アジマスのずれが増えます（普及モデル +8′、高級モデル +3′）。
- **ラベル**：テープを入れ替えるたびに、ラベルの紙とペンの色がランダムに変わります。表示中の面のアーティスト名と曲名を、手書き風に書き込みます。
  - アーティスト名と曲名は、ファイルのタグから読みます（MP3 の ID3v1/v2、FLAC の Vorbis コメント、M4A の iTunes タグ）。Shift_JIS で書かれた古い日本語の ID3 タグにも対応しています。
  - タグがなければ、「アーティスト - 曲名」形式のファイル名から読み取ります。
  - アーティストが 2 組ならスラッシュで並べ、3 組以上なら「○○ ほか」と書きます。
- **カセット窓**：実物の寸法で描いています。左右のテープの巻き量は再生位置から計算し、リールは実際の角速度で回ります（テープ速度 4.76cm/s）。再生中、2 つのリールは同じ向き（ラベル側から見て反時計回り）に回ります。高速で巻くときは、画面上で逆回りに見えないよう、1 コマあたりの回転量を抑えて描きます。

## 再生補正

再生するヘッドホンやスピーカーの癖を打ち消してから聴けます。補正は原音とカセットの両方に同じだけかかります。

| 形式 | 入手方法 |
|---|---|
| REW 測定データ（.txt） | REW の **File → Export → Export measurement as text** |
| AutoEQ `ParametricEQ.txt` / `GraphicEQ.txt` | [AutoEQ](https://github.com/jaakkopasanen/AutoEq) の結果から機種を探してダウンロード |
| Equalizer APO 形式のフィルタ | REW の EQ 書き出しなど |

最大ブースト（既定 +4dB）、補正範囲（既定 40Hz〜16kHz）、平滑化を調整できます。補正フィルタは最小位相 FIR です。

## 信号の流れ

```
音源 ─┬─────────────────────────────────────────────────────────── 原音
      └─ 録音レベル → [dbx 圧縮] → [ドルビー B/C/S 録音] → プリエンファシス → tanh 飽和 → ディエンファシス
           → (+ テープヒス → [ドルビーデコード]) → ワウ・フラッター（変調遅延）
           → [ドロップアウト・経年の高域低下] → アジマス（R 遅延） → 再生周波数特性（双二次 ×4）
           → [ドルビー B/C/S 再生] → [dbx 伸長] ────────────────────────────────────────────── カセット
                                                       ↓
                                       A/B → 音量 → 再生補正 → 出力
```

すべて Web Audio の標準ノード（BiquadFilter、WaveShaper、Delay、Oscillator など）で組んでいます。dbx の可変ゲインも、検出器の出力を GainNode のゲインに直接つないで作っています。AudioWorklet は使っていません。

## 公開方法

1. このリポジトリを GitHub に push します。
2. **Settings → Pages** で **Deploy from a branch** を選び、`main` / `/(root)` を指定します。
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

ローカルで開く場合は、`index.html` を直接開くか、`python3 -m http.server 8000` を実行して `http://localhost:8000/` を開きます。

## ファイル構成

```
index.html            UI・グラフ・Web Audio の信号経路
cassette.js           機種プリセットと音響モデル（ブラウザと Node の両方で動作）
deck.js               テープ長、A/B 面の曲配置、裏返し、リールの寸法（ブラウザと Node の両方で動作）
correction.js         再生補正（ファイル解析・逆特性・最小位相 FIR）
test/check-model.js   音響モデルの検証スクリプト
test/check-deck.js    テープ構造の検証スクリプト
```

## 検証

```bash
node test/check-model.js
node test/check-deck.js
```

次の項目を確認します。

- 各プリセットの −3dB 点が表記の範囲にあること
- ワウ・フラッターの成分の合計が公称値に一致すること
- ランダム揺らぎがつなぎ目なくループすること
- 普及モデルのモノラル合成で約 6.8kHz に打ち消しが出ること
- ドルビー B の扱い
- 最大出力レベルで歪み率が 3% になる校正

## 限界

- ドルビーは実機のスライディングバンドを、レベルに応じて変わるシェルフで近似しています。ドルビー C のスペクトラル・スキューイングとアンチサチュレーションは省略しています。
- 転写エコーは、遅延なしで再生するためポストエコーだけを再現しています（実際のテープでは、無音部の直前にプリエコーも出ます）。
- 経年劣化の数値は、一般的な傾向にもとづく推定です。保管状態（温度・湿度）による違いや、粘着化（スティッキー・シェッド）による鳴きは含みません。
- 録音機側のバイアス調整は含みません。
